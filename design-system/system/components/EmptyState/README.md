What a list or page shows when there is nothing yet: a round clay badge, a heading, one sentence and at most one action; copied from `src/app/shared/empty-state.ts` (`lms-empty-state`).

**Markup.** `.lms-empty` with `.badge` (a 24px icon), `h2`, `p` and `.actions`.

**Rules.**
- The heading is warm and specific ("Your learning starts here", "No bookmarks yet"); the message says how it fills up ("Press B or the bookmark button in any lesson to save your place.").
- After filtering, use "No courses match" / "Try other words, or clear the filters to see everything."
