# Logos

The Operation Forward logo: two forward chevrons (Forward Teal, then Forward Clay) and the name in Fraunces SemiBold, converted to outlines. All files are SVG; PNG exports and `favicon.ico` live with the source kit.

| File | Use |
|---|---|
| `logo-horizontal.svg` | Default on light backgrounds: websites, documents, email signatures. Chevrons `#1F5E5B` and `#B4532A`, name `#1F2A33`. |
| `logo-horizontal-reversed.svg` | On dark backgrounds. Chevrons `#7FC6BF` and `#E58E6C`, name `#ECE7E0`. |
| `logo-horizontal-ink.svg` / `logo-horizontal-white.svg` | One colour (`#1F2A33` / white): printing, stamps, embroidery, photos. |
| `logo-stacked.svg` / `logo-stacked-reversed.svg` | Square-ish spaces: event banners, social posts, merchandise. |
| `mark.svg`, `mark-reversed.svg`, `mark-ink.svg`, `mark-white.svg` | The chevrons alone, when the name is nearby or space is tight. |
| `app-icon.svg` | Profile pictures, app and browser icons: the reversed mark on an Ink tile. |
| `social-card.svg` | Link previews (1200×630). |

Clear space: a quarter of the mark's height on every side. Minimum size: horizontal logo 120px (30mm) wide; mark 16px (5mm) tall. Teal always comes first. Don't recolour outside the palette, stretch, rotate, add effects or reset the name in another typeface.
